# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - Unreleased

### Added
- Initial open-source project structure.
- Production Python packaging (`pyproject.toml`).
- Comprehensive documentation (`README.md`, `INSTALLATION.md`, `HOW_TO_USE.md`).
- Core agent modules moved to `src/veydrak/` namespace.
- Parallel code generation utilizing LangGraph `Send` API.
- Orchestrator graph with integrated Scratch Workspace and `pytest` testing.
- AI Review and Human-in-the-Loop (`__interrupt__`) node implementation.
- Time-travel debugging and streaming via `MemorySaver`.
- Example tutorials demonstrating standalone capabilities in `examples/`.
